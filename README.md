# Survival Analysis — Project & Notes

## Overview

This repository contains my work on Survival Analysis, including an
applied statistical analysis project and supporting study notes.

The repository is intended to document both the practical application
of survival analysis techniques and the theoretical concepts behind them.

## Repository Contents

### 1. Survival Analysis Project

The project applies survival analysis techniques to real data, including:

- Survival and hazard functions
- Censoring
- Kaplan-Meier estimation
- Survival curve comparison
- Log-rank test
- Cox proportional hazards model
- Model interpretation
- Proportional hazards assumption
- Schoenfeld residual analysis

### 2. Survival Analysis Notes

The `Notes` folder contains study material covering the theoretical
foundations of Survival Analysis, including formulas, concepts,
worked examples, and explanations of the methods used in the project.

## Key Topics

- Survival Function
- Hazard Function
- Censoring
- Kaplan-Meier Estimator
- Nelson-Aalen Estimator
- Log-Rank Test
- Cox Proportional Hazards Model
- Hazard Ratios
- Proportional Hazards Assumption
- Schoenfeld Residuals
- Survival Curve Analysis

## Tools Used

- R
- RStudio
- survival
- survminer
- ggplot2
- dplyr

## Purpose

This repository combines theoretical learning with practical
implementation to demonstrate how Survival Analysis can be used to
study time-to-event data.

The notes provide the theoretical foundation, while the project
demonstrates how these concepts can be implemented and interpreted
using real data.
